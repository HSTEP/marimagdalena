Set as plates instead, on a measure of five over six columns: a row of three at index scale, then a pair at reading scale. The first frame is the page header's plate, so twenty run here and twenty divides by five exactly — the sequence closes on a complete row. Each plate used to carry its number under a hairline, defended as "the only caption these frames can honestly hold". The honest conclusion was the other one: they hold none. A plate number exists so that running text can say "see plate 14" — nothing on this site cites one, so twenty-one figures and twenty-one rules were a numbering scheme with no referent, which is the look of a table with the column headings taken off. The shoot is named once, above; the frames are the frames. #}
